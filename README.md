# Ob-havo — React Native

Kichik Expo/React Native ob-havo ilovasi. Shahar nomi bo‘yicha qidiradi, joriy haroratni va 5 kunlik prognozni ko‘rsatadi.

## Ishga tushirish

```bash
npm install
npm start
```

Keyin Expo Go orqali QR-kodni skaner qiling yoki `a` tugmasi bilan Android emulatorni ishga tushiring.

Ilova Open-Meteo geocoding va forecast API’laridan foydalanadi, shuning uchun API key kerak emas.
